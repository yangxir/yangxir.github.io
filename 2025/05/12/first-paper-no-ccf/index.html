我不知道这是 C 类会议的时候，反而最投入

发表于2025-05-12|更新于2025-05-22|科研与成长
|浏览量:

写在一个下过雨的夜晚，回忆起研究室灯光下最亮的那段时光

我第一次知道 COMPSAC 是 C 类会议，
不是从别人嘴里听来的，而是论文投出去之后，我随口问了 ChatGPT。

它说：“这是 CCF-C 类。”

我一愣：“C 类？那是好还是不好？”

我打开知乎搜索“CCF-C 是什么水平”——
然后像打开了潘多拉的盒子：

“C 类会议没人看。”
“水文、毕业用。”
“这种会议发出来都羞于提起。”

我这才意识到，原来科研圈也有一整套“等级”“含金量”的鄙视链。

但其实，写这篇论文的时候，我根本不知道这些事。

起初我只是听从教授的建议：“这个会议方向挺合适你。”
于是我就开始写了，甚至没查过会议名字在排行榜上的位置。

这就是我学术写作的起点——
一次完全不以“回报”或“排名”为动机的尝试。

我不是为了什么“会议等级”去写的，
只是觉得自己终于遇到了一个值得全力以赴去搞清楚的问题。

那段时间真的很特别。

每天我都写一版稿子，发给教授，
教授回我一整页批注。

我在便利店买晚饭，晚上坐在研究室改逻辑、补实验、画图表；
论文定了主线，又砍掉，写完结论，又推翻重写。
最疯狂的一天，我凌晨打车回家，仙台的夜风吹得我迷糊，
但我却感到无比清醒和满足。

我知道，我在做一件我真心喜欢的事。
不是任务，不是 KPI，是创造。

等论文投出后，我才开始了解科研圈的“规则”：

什么是 A 类、B 类、C 类；
什么是 Top Conference，什么是水会。

说不失落是假的。
但我更清楚的是：我不是为了别人认可这件事而做的。

如果我一开始就知道它是 C 类，
也许我会犹豫、会畏缩，甚至根本不会动笔。

但当时的我什么都不知道，所以选择了最纯粹地去写、去搞懂、去打磨每一句话。

这难道不是科研最初该有的模样吗？

很多人说：“科研要有目标，要规划路线，要冲顶会。”

我理解这套说法，也知道它有现实意义。
但我更在意的，是我能不能一直保有那种：

“我全力以赴了”的热情感。

你可以说它是 C 类，是边角料，是没含金量的 Workshop；
但我会记得，那是我第一次真正写出属于自己的论文，
第一次在没有奖赏的前提下，把所有热情倾注在一个课题上。

不是因为它高分我才认真，
而是因为我认真了，它才真正变得重要。

以后我也许会投 A 类，也许会上更大的讲台，也许不会；
但这段“什么都不懂就开始写”的经历，
是我科研旅程中最干净、最投入的一步。

哪怕它在别人眼中“不值钱”，
对我来说，它一点都不水。

它记录了我——那个真正热爱、真正努力的自己。

如果你也正在写第一篇论文，不要怕不知道方向、分不清会议等级。
只要你是真诚地写出了自己的思考，那就已经很了不起了。
