求职与读博抉择总结

📅 2024年底至2025年初求职经历回顾

📝 一、求职经历与时间线

短短数月内，我经历了多家日本公司的面试，包括 Freee、Line Yahoo、GMO Internet 和 IIJ，具体过程如下：

日期 公司 面试环节 结果
2024.12.02 Line Yahoo Coding Test 放弃
2024.12.03 Freee Coding Test ✅ 94%通过
2024.12.09 Freee 一面 ✅
2024.12.16 Freee 人事面 ✅
2024.12.20 Freee 二面 ✅
2025.01.07 Freee 终面 ✅
2025.01.24 Freee 终面2.0 ❌ 失败
2025.01.15 GMO Internet ES通过 ✅
2025.01.27 GMO Internet 一面 ❌ 失败
2025.01.15 IIJ WEBTEST ✅ 通过
2025.01.28 IIJ 一面 ❌ 失败

💬 二、面试经验与失败原因总结

通过几家公司的面试经历，我总结了各家公司的考察特点：

  • Freee 对技术要求较高，尤其关注项目的具体实现细节和优化思路。
  • GMO Internet 更注重个人的职业规划、沟通能力和团队合作意识。
  • IIJ 则更加侧重于基础的网络通信知识和实际项目经验。

失败的原因多为：

  • 面试准备不够充分，未能深入展示项目的细节与成果。
  • 沟通表达不足，未能充分体现自身的优势与技术深度。
  • 职业规划问题未能给出清晰明确的回答。

💡 三、求职失败后的思考与成长

求职过程中的多次失败让我意识到：

  • 面试中的沟通能力和自信态度比预想中更加重要。
  • 必须深入理解和准备自己参与过的项目，而非停留于表面。
  • 明确个人职业规划非常关键，企业倾向招聘对未来有清晰规划的人。

🎓 四、为何最终决定读博？

—— 家庭、导师、兴趣的多重影响

在求职过程中经历了几次失败后，我不得不重新思考自己的未来。是继续寻找工作，还是转向更深入的学术研究？最终，我基于以下几个核心因素做出了选择：继续攻读博士学位。

🏡 家庭的影响：学术氛围下的成长

我的家人中，大部分都是教授，从小到大，我的成长环境充满了学术讨论和研究氛围。在这样的家庭背景下，继续深造似乎是一条很自然的路，家人也从未把博士当作一个“遥不可及”的目标，而是认为它是一个顺其自然的过程。
家人给我的建议是：

  • 博士学历在长期来看更具竞争力，无论未来是进入企业还是留在学术界，都会有更大的选择空间。
  • 读博不仅仅是学习，更是一种专业能力的积累，尤其是在高科技领域，深入研究比单纯的工作经验更重要。
  • 未来如果进入企业，博士背景会成为一个独特优势，特别是在 AI、网络安全、通信等领域，博士背景往往会带来更好的发展机会。

虽然家人支持我做任何选择，但他们的建议让我开始认真思考：我是否真的准备好进入职场，还是应该趁现在继续深造？

👨‍🏫 教授的认可：他认为我在这个方向有潜力

在这段时间里，我也和我的导师进行了多次交流。他对我的研究能力给予了高度评价，并认为我在 EAP-TLS 认证优化 和 跨国 WiFi 认证安全 领域有很大的潜力。他的建议包括：

  • 博士阶段能积累更深入的研究经验，如果未来考虑进入高端研发岗位，博士学位将是重要的敲门砖。
  • 读博不会限制未来的选择，相反，博士生涯可以让我在学术界、企业研究院、甚至创业等多个方向上找到合适的机会。

导师的支持让我意识到，我并不是因为找不到工作才去读博，而是我确实具备这个能力，并且这个领域值得深入研究。

🔬 研究的乐趣：我真的喜欢探索新技术

除了外部因素，我自己的内心也在告诉我：我喜欢做研究，喜欢解决问题的过程。
回顾过去的实验经历，我发现：

  • 当我成功优化认证系统时，那种成就感远超找工作的喜悦。比如我在 Radius Server 认证优化实验中成功降低了延迟，这种实践带来的满足感让我更有动力继续深入研究。
  • 相比日常业务开发，我更享受探索和优化的过程，在实验室里，我可以自由尝试新的方法，而不是被企业的业务需求所限制。
  • 失败和调试的过程让我感到充实，当实验失败时，我会花很多时间去分析问题、调整方案，而不是因为“任务完成了”就结束。

求职的挫折让我意识到：比起单纯找份工作，我更想去探索和创造新的技术。

🎯 综上：为什么我最终选择读博

  • 家庭背景影响：在学术氛围中成长，家人对博士阶段的理解和支持让我觉得这条路是可行的。
  • 导师的认可：教授认为我在这个领域有发展潜力，并愿意支持我继续研究。
  • 研究的乐趣：相比起进入企业做日常开发，我更喜欢研究和探索新技术的过程。
  • 博士不会限制未来的选择，相反，它会让我未来拥有更多的可能性，无论是进入企业研究院、继续学术研究，还是结合产业创业，读博都会成为一个有力的支撑。

📌 这不是逃避，而是一次深思熟虑后的选择。
📢 如果你也在面临类似的抉择，不妨问问自己：你真正想要的是什么？ 😊
